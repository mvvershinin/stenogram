# Стенограмма — инструкции для Claude Code

Инструмент превращает запись видеоконференции в стенограмму диалога с разбивкой по
участникам. Работает офлайн на CPU.

## Первым делом

Перед любой содержательной работой прочитай:

1. [`.docs/domain.md`](.docs/domain.md) — термины и границы продукта
2. [`.docs/decisions/`](.docs/decisions/) — почему сделано именно так, с замерами
3. [`docs/архитектура.md`](docs/архитектура.md) — слои и поток данных

Половина предлагаемых улучшений отменяет решения, принятые по результатам экспериментов.

## Команда агентов

Одиннадцать ролей: координатор, три технических эксперта, три бизнес-роли, четыре роли
контроля качества. Состав и маршрутизация — [`.docs/agents.md`](.docs/agents.md),
краткая шпаргалка — [`.claude/agents/README.md`](.claude/agents/README.md).

Задача больше трёх файлов, новая фича или рефакторинг — начинай с `/orchestrate`.

## Обязательные проверки

**После изменения кода:**

```
/validate    слои и зависимости
/review      баги и режимы отказа
```

**После изменения в разметке участников — дополнительно `/measure` до и после**
и чтение трёх минут стенограммы глазами. Числа ловят регресс, чтение ловит бессмыслицу.

**После изменения в работе с ffmpeg (`audio`, `video`, кэш звука в сервисе)** — `pytest -m ffmpeg`
в корне и в `service/`. В CI эти тесты не запускаются.

**Перед публикацией:** `/privacy-check`.

## Три вещи, которые ломают проект незаметно

**Порядок этапов.** Распознавание идёт ДО разметки участников: границам подсветки нужны
паузы между словами. Обратный порядок не падает, просто ухудшает результат.

**Умолчания.** `stay = 0.80`, `lag = 1.2`, порог надёжной реплики 1.5 с,
`word_timestamps=True`, `condition_on_previous_text=False` — за каждым стоит эксперимент.
Меняешь — приноси новый замер.

**Тяжёлые импорты.** `faster_whisper`, `sherpa_onnx`, `sklearn` импортируются внутри
функций, иначе `--help` ждёт загрузки ONNX Runtime.

## Приоритет сигналов

Видео (подсветка активного говорящего) надёжнее голосовых отпечатков на порядок.
Отпечатки — вспомогательный сигнал для разделения людей внутри одной плитки, их потолок
около 85% на уровне реплики. Решение, понижающее роль видео, требует записи
в `.docs/decisions/`.

## Данные

Записи содержат персональные данные. В репозиторий не попадают ни записи, ни результаты,
ни настоящие имена в примерах документации. Тестовые фикстуры — синтетические.
Регламент — [`.docs/privacy.md`](.docs/privacy.md).

## Проверка изменений

Полный прогон на часовой записи — 35 минут, для итераций не годится. Быстрая проверка:

```bash
./stenogram.sh фрагмент.mp4 -m small -l ru -f txt -o /tmp/проверка
```

Минута записи проходит весь пайплайн примерно за минуту.
