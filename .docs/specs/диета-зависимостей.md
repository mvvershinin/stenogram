# Спецификация: диета зависимостей

**Статус:** к работе · **Приоритет:** первый · **Оценка:** 1–2 дня

Соответствует этапу 0 из [`docs/план-развития.md`](../../docs/план-развития.md).

## Задача

Сократить окружение с 1.1 ГБ до 350–450 МБ, не изменив результат на тестовой записи.

Работа полезна независимо от того, будет ли десктопное приложение: она ускоряет
установку, упрощает офлайн-перенос и снимает лишние зависимости.

## Работы

⬜ **Убрать scikit-learn и scipy** — минус 188 МБ
⬜ написать `kmeans` на numpy: инициализация k-means++, веса по длительности, ~40 строк
⬜ сверить метки со старой реализацией на тестовой записи
⬜ `/measure` — согласованность половин не должна просесть ниже 85% при k=7
⬜ убрать `scikit-learn` из `requirements.txt`

⬜ **Убрать PyAV** — минус 104 МБ
⬜ передавать в `asr.transcribe` numpy-массив вместо пути к файлу
⬜ звук уже загружен через `audio.load_wav` — лишнее декодирование убирается
⬜ проверить, что потайминговка по словам не изменилась
⬜ исключить `av` из сборки

⬜ **Урезать ffmpeg** — минус ~340 МБ
⬜ отказаться от `ffprobe`: длительность и наличие видеодорожки достаёт сам `ffmpeg`
⬜ собрать минимальный статический бинарник
⬜ проверить на наборе контейнеров и кодеков

## Минимальная сборка ffmpeg

Нужно и достаточно:

- демуксеры: mp4, matroska, ogg, wav, mp3
- декодеры: h264, aac, mp3, opus, vorbis, pcm_s16le
- фильтры: `fps`, `crop`, `scale`, `aresample`, `highpass`, `afftdn`, `dynaudnorm`
- энкодеры: `rawvideo`, `pcm_s16le`
- протокол: file

Фильтры `highpass`, `afftdn`, `dynaudnorm` нужны только для `--denoise`, но выбрасывать
их незачем — они ничего не весят.

## Критерии готовности

⬜ окружение укладывается в 450 МБ
⬜ `/measure` на тестовой записи: числа в пределах шума от эталонных
⬜ офлайн-прогон проходит целиком
⬜ набор тестовых файлов с разными контейнерами открывается
⬜ `docs/эксплуатация.md` обновлён: новые цифры веса

## Риски

**Урезанный ffmpeg не откроет чью-то запись.** Смягчение: набор тестовых файлов с разными
контейнерами; запасной путь — если системный ffmpeg есть, использовать его.

**Свой k-means разойдётся с sklearn.** Смягчение: сверка меток на тестовой записи до
замены; расхождение допустимо только в пределах шума метрики.
