# 0003. HMM-сглаживание меток, а не дробление реплик на окна

**Дата:** 2026-08-16 · **Статус:** принято

## Контекст

Голосовые отпечатки коротких реплик шумят: соседние реплики одного человека получают
разные метки, и монолог рассыпается на нескольких «участников». На тестовой записи
кластеризация без сглаживания давала **419 смен говорящего**.

## Варианты

1. **Дробление реплик на окна по 2.5 с.** Идея — ловить смену говорящего внутри слишком
   длинного сегмента.
2. **Кластеризация интервалов подсветки целиком.** Гипотеза: подсветка переключается при
   смене говорящего, значит внутри интервала один человек.
3. **HMM-сглаживание (упрощённый VBx).** Штраф за смену говорящего, вероятность которой
   зависит от длины паузы.

## Что показали проверки

**Вариант 1 отвергнут.** Дробление на окна разрезало монологи в лапшу: отпечаток по
2.5-секундному окну слишком шумный, участник менялся каждые пару секунд посреди связной
речи. Числа выглядели терпимо — забраковало чтение стенограммы.

**Вариант 2 отвергнут.** Согласованность половин интервала — всего 42–48%. Причина: люди
в переговорной говорят по очереди, а плитка не меняется, потому что камера одна. Гипотеза
верна для раздельных подключений и неверна для общей переговорной.

**Вариант 3 принят.** Замеры при k=7:

| `stay` | Смен говорящего | Согласованность половин |
|---:|---:|---:|
| без сглаживания | 419 | — |
| **0.80** | **194** | **85.4%** |
| 0.88 | 128 | 83.5% |
| 0.94 | 110 | 77.4% |

## Решение

HMM поверх последовательности реплик: состояния — участники, эмиссия — косинус к
центроиду, умноженный на корень длительности; вероятность остаться тем же участником
уменьшается с длиной паузы. Декодирование Витерби, 6 итераций с пересчётом центроидов.
Значение по умолчанию **`stay = 0.80`**.

## Последствия

- Число ложных переключений упало более чем вдвое без потери качества центроидов.
- `stay` выше 0.88 пережимает: один участник начинает поглощать чужие реплики. При
  глобальном сглаживании со `stay = 0.92` один участник забрал 44% времени.
- Метрику «число смен» нельзя смотреть отдельно от распределения долей — иначе
  пережатое сглаживание выглядит улучшением.
