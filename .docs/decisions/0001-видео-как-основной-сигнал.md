# 0001. Подсветка активного говорящего — основной сигнал разметки

**Дата:** 2026-08-16 · **Статус:** принято

## Контекст

Задача: разметить, кто говорит, на часовой записи видеоконференции из общей переговорной.
Классический подход — голосовые отпечатки — на этом материале работал плохо: эхо
помещения, один микрофон на семерых, похожие голоса.

Показательный замер: косинус между центроидами двух заведомо разных групп участников
оказался **0.958**. Отпечатки почти не различают людей — их забивают характеристики
канала: кодек, реверберация, общий тракт.

## Варианты

1. **Только отпечатки.** Классика, но на этом материале давала разорванные монологи
   и слипшихся людей.
2. **Более сильная модель отпечатков.** Проверено четыре модели, лучшая дала 83% —
   потолок, а не решение.
3. **Подсветка активного говорящего из видео.** Сервисы видеосвязи обводят рамкой плитку
   говорящего.

## Решение

Основной сигнал — **подсветка из видео**. Отпечатки понижены до вспомогательной роли:
они делят людей внутри одной плитки, где видео бессильно.

## Замеры

- 18951 кадр при 5 к/с, 324 переключения;
- **ровно одна плитка подсвечена практически всегда** — ни одного кадра с двумя
  подсвеченными, без подсветки — 2 кадра из 18951 (перепроверено 26.08.2026).
  Сигнал бинарный и чистый;
- разбор часа видео — **16 секунд**: полоска каждой рамки усредняется в один пиксель
  на кадр.

## Последствия

- Порядок этапов изменился: распознавание идёт **до** разметки участников, потому что
  границам подсветки нужны паузы между словами (см. [0005](0005-порядок-этапов.md)).
- Появилась зависимость от видеодорожки. Для аудиофайлов и записей без подсветки шаг
  пропускается, работает старый путь через отпечатки.
- Качество стало неоднородным: разметка по видео надёжна, по звуку — приблизительна.
  Это честно вынесено в документацию, чтобы пользователь понимал, чему доверять.
