# 0004. Без PyTorch: ONNX Runtime и CTranslate2

**Дата:** 2026-08-16 · **Статус:** принято

## Контекст

Очевидный путь для диаризации — `pyannote.audio 3.1`, лучшее решение в своём классе.
Оно тянет PyTorch и требует токен Hugging Face с принятием условий на каждую gated-модель.

## Варианты

1. **pyannote.audio + PyTorch.** Лучшее качество из коробки.
2. **sherpa-onnx + ONNX Runtime.** Те же модели в ONNX-сборке от k2-fsa, свободные,
   без токенов.

## Решение

**Вариант 2.** Сегментация — `pyannote-segmentation-3.0` в ONNX, отпечатки — CAM++,
распознавание речи — faster-whisper на CTranslate2.

## Обоснование

- **PyTorch весит около 2.5 ГБ** — больше, чем всё остальное окружение вместе взятое.
  Для инструмента, который должен ставиться одним скриптом, это неподъёмно.
- **Gated-модели ломают установку.** Токен, регистрация, принятие условий — три шага,
  на которых пользователь отваливается, и офлайн-развёртывание усложняется.
- Кластеризацию и сглаживание всё равно пишем сами, то есть берём у pyannote только
  сегментацию — а она доступна в ONNX.

## Последствия

- Установка не требует ни токенов, ни регистрации, ни PyTorch.
- Качество сегментации то же — модель та же самая, отличается только рантайм.
- Кластеризация и сглаживание — наш код, что оказалось скорее плюсом: под этот материал
  их пришлось настраивать (см. [0003](0003-сглаживание-вместо-дробления.md)).
- Путь на GPU иной, чем у pyannote: через CTranslate2 (`--device cuda`), и он покрывает
  только распознавание, самый долгий этап.
