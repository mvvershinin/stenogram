# 0002. CAM++ как модель голосовых отпечатков

**Дата:** 2026-08-16 · **Статус:** принято

## Контекст

Нужно выбрать ONNX-модель голосовых отпечатков для разделения людей внутри одной плитки.
Эталонной разметки нет, поэтому сравнивать модели по точности напрямую нельзя.

## Варианты

Четыре свободные модели из релизов sherpa-onnx: CAM++ (VoxCeleb), ResNet34-LM (VoxCeleb),
TitaNet-large, CAM++ (3D-Speaker zh/en). Плюс ансамбль из склеенных нормированных
векторов всех четырёх.

## Как сравнивали

Силуэт для сравнения не годится — он несравним между разными пространствами эмбеддингов.
Введена метрика без разметки: **согласованность половин реплики**. Реплику длиннее
3 секунд делим пополам, считаем отпечаток каждой половины и смотрим, попадут ли обе
к одному участнику. Обе половины — заведомо один человек.

## Замеры

Проверено на 370 репликах:

| Модель | Размерность | Согласованность |
|---|---:|---:|
| **CAM++ (VoxCeleb)** | 512 | **83.0%** |
| TitaNet-large | 192 | 63.2% |
| CAM++ (3D-Speaker zh/en) | 192 | 53.8% |
| ResNet34-LM (VoxCeleb) | 256 | 47.8% |
| Ансамбль четырёх | 1152 | 80.3% |

Согласие моделей между собой по индексу Ранда — 0.03–0.38: слабые модели дают почти
случайные разбиения.

## Решение

**CAM++ (VoxCeleb)**, 512 измерений. Ансамбль отвергнут: слабые участники вносят больше
шума, чем пользы.

## Последствия

- Модель весит 28 МБ, качается при установке в `~/.cache/stenogram`.
- Потолок качества на записях из общей переговорной — около 85% на уровне реплики.
  Выше без смены класса моделей не подняться.
- При замене модели обязателен повторный замер тем же протоколом, иначе сравнение
  недействительно.
