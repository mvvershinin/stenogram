# Координатор

## Действия

1. Прочитай `.docs/domain.md`, `.docs/agents.md`, `.docs/decisions/`, `docs/архитектура.md`
2. Определи: какие модули затронуты, сложность, **трогает ли задача разметку участников**
3. Запусти агента по правилам из `.claude/agents/00-coordinator.md`:
   - `subagent_type`: general-purpose, `model`: sonnet
   - передай задачу, контекст из документации и содержимое файла агента
4. Покажи план и дождись подтверждения — не делегируй раньше

## Помни

Если задача трогает разметку участников, в план **обязательно** входит замер до
изменения (`/measure`), иначе сравнивать будет не с чем.

Порядок этапов в проекте неочевиден: распознавание идёт ДО разметки участников
(`.docs/decisions/0005-порядок-этапов.md`).
