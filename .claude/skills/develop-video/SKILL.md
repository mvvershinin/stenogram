# Детектор активного говорящего

## Действия

1. Прочитай `docs/алгоритмы.md` раздел 3 и `.docs/decisions/0001-видео-как-основной-сигнал.md`
2. Запусти Agent: `subagent_type` general-purpose, `model` opus,
   правила из `.claude/agents/03-video-expert.md`
3. После изменений в `to_turns` — проверь долю границ, попавших внутрь слова
   (эталон 6.5%, до обработки было 71%)

## Контекст

Модуль `stenogram/video.py` — отличительная часть проекта, даёт качество, недостижимое
голосовыми отпечатками.

Держать в голове: плитки ищутся по корреляции мерцания, а не по геометрии — раскладка
не важна. Скорость держится на том, что из кадра берутся только тонкие полоски: час
видео за 16 секунд. Детектор обязан мягко отказывать — не нашлось плиток, значит пустой
список, а не исключение.
