# Сборка и зависимости

## Действия

1. Прочитай `docs/план-развития.md` и `.docs/decisions/0004-без-pytorch.md`
2. Запусти Agent: `model` sonnet, правила из `.claude/agents/10-packaging-expert.md`
3. После изменений в зависимостях — обязательная проверка офлайна

## Главная задача

Окружение весит 1.1 ГБ, три четверти устранимы: `static_ffmpeg` 376 МБ (два бинарника
по 188 МБ), `scipy` + `sklearn` 188 МБ (ради одной функции `KMeans`), PyAV 104 МБ
(не нужен — `transcribe` принимает numpy-массив).

Цель: 1.1 ГБ → 350–450 МБ без изменения результата.

## Проверка офлайна

```bash
env HF_HUB_OFFLINE=1 \
    http_proxy=http://127.0.0.1:1 https_proxy=http://127.0.0.1:1 \
    ./stenogram.sh запись.mp4
```

Прогон обязан пройти целиком.

## Принципы

Не тянуть PyTorch (весит больше всего остального вместе). Не тянуть gated-модели
(токены ломают установку и офлайн). Модели качаются при установке, в репозитории их нет.
Права root не нужны.
