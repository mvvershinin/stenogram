# Ревью

## Действия

1. Собери изменение: `git diff`, `git diff --staged` или указанные файлы
2. Запусти Agent: `subagent_type` general-purpose, `model` opus,
   правила из `.claude/agents/08-code-critic.md`
3. Верни отчёт с вердиктом APPROVE / REQUEST_CHANGES / BLOCK

## Задача агента

Найти, **чем сломать код**, а не пересказать, что он делает.

Каждая находка — с конкретным сценарием: какие входные данные, что произойдёт.
Без сценария это подозрение, а не находка.

## Где в этом проекте обычно ломается

Пустые последовательности (запись без речи, видео без плиток), деление на ноль,
выход за границы массивов, нарушенный порядок реплик, сравнение времён на равенство,
лишние копии массива на 242 МБ, молчаливые `except`.

Отдельно: порядок этапов. Вызов разметки до распознавания не падает — просто ухудшает
результат. Ловится только чтением.

## Чего не делать

Не спорить с решениями из `.docs/decisions/` — умолчания получены замерами.
Не предлагать вкусовщину. Не выдумывать замечания ради веса отчёта.
