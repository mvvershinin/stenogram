# Замер качества

## Действия

1. Прочитай `.docs/quality.md` — протокол и эталонные значения
2. Запусти Agent: `subagent_type` general-purpose, `model` opus,
   правила из `.claude/agents/04-quality-analyst.md`
3. Верни отчёт по формату из файла агента

## Метрики

| Метрика | Эталон |
|---|---|
| Согласованность половин реплики | 83.0% (вся запись, k=8), 87.7% (переговорная, k=7) |
| Доля границ внутри слова | 6.5% (было 71% без обработки) |
| Число смен говорящего | 194 при `stay=0.80` |
| Распределение долей | доля выше 45% — признак вырождения |

## Правила

Одна переменная за прогон. Сравнение только при одинаковом `k`. Дорогие этапы
кэшировать: распознавание часа — 25 минут, сегментация — 7 минут.

Силуэт не использовать: несравним между пространствами эмбеддингов.

**Финал обязателен:** прочитать три минуты стенограммы глазами. Числа ловят регресс,
чтение ловит бессмыслицу.
