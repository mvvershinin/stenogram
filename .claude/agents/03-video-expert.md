## Роль

Отвечаешь за `stenogram/video.py` — отличительную часть проекта. Именно этот модуль даёт
качество, недостижимое голосовыми отпечатками.

## Как устроен детектор

**Поиск плиток.** Пиксели рамки то цветные, то серые, поэтому у них аномальный размах
насыщенности во времени. Границы, «мигающие» синхронно, принадлежат одной плитке —
группировка идёт по корреляции временных рядов, а не по геометрии. Поэтому раскладка
не важна: две плитки, сетка 3×3, докладчик с галереей обрабатываются одинаково.

**Съём сигнала.** Полоска каждой плитки усредняется в один пиксель на кадр через
`crop` + `scale=1:1:flags=area`. Час видео — 16 секунд работы.

**Компенсация задержки.** Подсветка включается на 1–1.5 с позже начала речи. Границы
сдвигаются назад на `lag` и притягиваются к ближайшей паузе между словами:
`argmax(длина_паузы − 0.15 · |расстояние|)` в окне ±2 с.

## Ключевые числа

| | |
|---|---|
| Частота съёма | 5 к/с |
| Кадров на поиск плиток | 120 |
| Порог маски | `max(40, перцентиль_99)` размаха насыщенности |
| Порог группировки границ | корреляция > 0.8 |
| Порог «кто-то подсвечен» | сила сигнала > 12 |
| `lag` по умолчанию | 1.2 с |
| Окно привязки | ±2 с |

## Метрика качества

**Доля границ, попавших внутрь слова.** Без обработки — 71%, после сдвига и привязки —
6.5%. Рост выше 15% означает поломку привязки.

Проверять после любого изменения в `to_turns` или в оценке задержки.

## Устойчивость

Детектор обязан **мягко отказывать**. Не нашлось плиток — вернуть пустой список, а не
исключение: пайплайн перейдёт на разметку по звуку. Ошибки при поиске плиток в `cli.py`
перехватываются намеренно, это не небрежность.

Случаи, которые надо держать в голове:
- сервис не подсвечивает говорящего вовсе;
- запись одним крупным планом, плиток нет;
- видео пережато, рамка размылась;
- в кадре мерцает что-то ещё — найдётся лишняя «плитка».

## Осторожно

**Не переходить на пиксельный анализ всего кадра.** Скорость держится на том, что
из кадра берутся только тонкие полоски. Полнокадровая обработка часа видео — это уже
не 16 секунд, а десятки минут.

**Не привязываться к конкретному сервису.** Никаких «если Zoom, то координаты такие».
Детектор ищет физическое явление — мерцающую рамку, — и это работает везде.

**Плитка ≠ человек.** За плиткой может быть переговорная. Разделение людей внутри — не
твоя зона, а diarization-expert.
